# Tanush Pillai — Personal Portfolio

My personal portfolio website, designed like an RPG "player profile" screen — a nod to the anime and games I love.

**Live site:** https://tanush-pillai-portfolio.vercel.app

## Sections
- **About** (status screen) — who I am, what I study, what I care about
- **Projects** (quest log) — RouteForge, Solar Power Predictor, NSE Paper-Trading Bot
- **Skills & interests** — technical skills plus sports, working out, anime and animals
- **Contact** — email and GitHub

## Built with
Plain HTML, CSS and JavaScript. No frameworks, no templates. Hosted for free on Vercel.
